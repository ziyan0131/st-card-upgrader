# 🌸 角色卡升级工具 - SillyTavern 扩展

AI 驱动的角色卡版本升级工具。选择已有角色卡，编写修改指令，让 AI 自动生成升级版本并导入。

## ✨ 功能

- **选择角色卡**：从酒馆已有角色卡中选择需要升级的角色
- **预览角色信息**：查看角色卡的所有字段和关联世界书
- **灵活选择修改项**：可自由勾选需要 AI 修改的字段（描述、人设、场景、首条消息、系统提示词、对话示例、世界书）
- **AI 智能修改**：输入自然语言指令，AI 根据你的要求生成升级内容
- **自动版本管理**：自动检测当前版本号，生成下一个大版本（1.0 → 2.0 → 3.0）
- **一键导入**：生成结果可直接导入为新角色卡
- **世界书支持**：支持查看和修改角色卡携带的世界书/知识库

## 📦 安装

### 方法一：通过 URL 安装（推荐）

1. 打开 SillyTavern
2. 点击扩展面板 → 安装扩展
3. 输入本仓库 URL：
   ```
   https://github.com/你的用户名/st-card-upgrader
   ```
4. 点击安装

### 方法二：手动安装

1. 将本仓库克隆到 SillyTavern 的第三方扩展目录：
   ```bash
   cd SillyTavern/public/scripts/extensions/third-party/
   git clone https://github.com/你的用户名/st-card-upgrader.git
   ```
2. 重启 SillyTavern

## 🎮 使用方法

1. 在扩展菜单中点击 **「角色卡升级工具」** 按钮进入
2. 从下拉列表中选择要升级的角色卡
3. 查看角色卡信息和世界书内容
4. 勾选需要 AI 修改的字段
5. 在文本框中输入修改指令，例如：
   - "让角色性格更加温柔，增加更多外貌细节"
   - "丰富世界观设定，增加三个新的知识库条目"
   - "优化首条消息，使开场更加引人入胜"
6. 点击 **🚀 生成升级版角色卡**
7. 预览结果，确认后点击 **📥 导入为新角色卡**
