# 🌸 角色卡升级工具 v2.4 - SillyTavern 扩展

选择已有角色卡，手动编辑或 AI 修改，一键上传为新版本到酒馆。

## 功能

- 🔍 搜索选择角色卡
- 🖼️ 显示/更换角色卡头像
- ✏️ 手动编辑所有字段（所有输入框支持拖拽放大/缩小）
- 📌 创作者注释、🏷️ 角色标签（可自由增删）已并入「角色卡信息」
- 📖 世界书增删改
- 💬 开场白支持勾选单条或按范围（第 N 条到第 M 条）进行 AI 修改
- 🤖 每个字段独立 AI 修改 + AI 一键全局修改（**只调用一次 API**）
- 🔍 AI 一键修改后展示「修改前后对比」并需点击「确认修改」才生效
- 📤 直接上传为新版本角色卡到酒馆（带头像）
- 💾 下载 JSON
- ⚙️ 右上角 API 配置：留空自动跟随酒馆主 API，也可填写自定义 OpenAI 兼容地址/Key/模型，并支持真实连通性测试

## 安装

SillyTavern → 扩展 → 安装扩展 → 输入仓库地址
