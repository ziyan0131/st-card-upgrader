# 🌸 角色卡升级工具 - SillyTavern 扩展

AI驱动的角色卡版本升级工具。选择已有角色卡，手动编辑或使用AI指令修改，一键上传为新版本。

## ✨ 功能

- **搜索 & 选择角色卡**：从酒馆已有角色中搜索选择
- **手动编辑**：直接修改描述、人设、场景、开场白、系统提示词、对话示例
- **世界书编辑**：查看/增删/修改角色卡携带的世界书条目
- **AI单字段修改**：每个字段都可独立使用AI修改
- **AI一键全局修改**：勾选要修改的字段，一次性AI升级
- **自动版本管理**：自动检测版本号，生成下一版本（1.0→2.0→3.0）
- **一键上传**：直接上传为新角色卡到酒馆
- **下载JSON**：可下载为标准 chara_card_v2 JSON 文件
- **独立浮窗**：不覆盖酒馆界面，可拖拽、缩放、全屏
- **手机适配**：适配移动端局域网访问

## 📦 安装

### 方法一：通过酒馆扩展安装器

1. 打开 SillyTavern → 扩展 → 安装扩展
2. 输入仓库地址：`https://github.com/你的用户名/st-card-upgrader`
3. 安装后重启酒馆

### 方法二：手动安装

```bash
cd SillyTavern/data/default-user/extensions/third-party/
git clone https://github.com/你的用户名/st-card-upgrader.git
```

## 🎮 使用

1. 点击左下角魔法棒菜单 → **角色卡升级工具**
2. 或在扩展设置面板 → **角色卡升级工具** → 打开
3. 搜索并选择角色卡
4. 手动编辑各字段，或使用每个字段的AI修改功能
5. 也可使用「AI一键全部修改」批量升级
6. 点击「上传为新版本角色卡」导入酒馆
